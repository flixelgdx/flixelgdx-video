# Code of Conduct

FlixelGDX Video follows the same Code of Conduct as the base [FlixelGDX](https://github.com/flixelgdx/flixelgdx) framework.

Please read it in full here: [FlixelGDX Code of Conduct](https://github.com/flixelgdx/flixelgdx/blob/master/CODE_OF_CONDUCT.md)

All of those rules apply to this repository and its spaces equally, including GitHub issues, pull requests, and any other
spaces where you are acting as a representative of FlixelGDX Video.
