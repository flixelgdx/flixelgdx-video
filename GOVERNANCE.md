# Governance

FlixelGDX Video is part of the [FlixelGDX Foundation](https://github.com/flixelgdx) and follows the same governance
model as the base [FlixelGDX](https://github.com/flixelgdx/flixelgdx) framework.

Please read the full governance document here: [FlixelGDX Governance](https://github.com/flixelgdx/flixelgdx/blob/master/GOVERNANCE.md)

This includes the role definitions (Project Leader, Maintainer, Contributor), the decision-making process, and
the versioning policy. Everything in that document applies to this repository as well.
